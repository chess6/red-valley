# Setup

One-time environment setup for Red Valley. See `CLAUDE.md` for day-to-day
commands once this is done, and `tools/doctor.sh` to check it's all still
in place.

## 1. Godot 4.7

This project targets Godot **4.7** specifically (not 4.x generally).

Download the Linux binary from https://godotengine.org/download/linux/ and
place it wherever you like; this repo's docs/scripts assume:

```
/opt/Godot4/Godot_v4.7-stable_linux.x86_64
```

If your path differs, everything in `CLAUDE.md`/`README.md` still works —
just substitute your path for that one.

Sanity check:

```bash
/opt/Godot4/Godot_v4.7-stable_linux.x86_64 --version
```

## 2. Blender 5.1

Assets are generated by script — no Blender assets are hand-built or
downloaded — but Blender itself is required to run the generator and (via
MCP, see below) for interactive asset work.

Download from https://www.blender.org/download/, targeting **5.1**. This
repo's docs assume:

```
/opt/blender/blender
```

Sanity check:

```bash
/opt/blender/blender --version
```

Regenerate all placeholder assets (writes `assets/models/*.glb`):

```bash
/opt/blender/blender --background --python tools/blender/gen_assets.py
```

## 3. Blender MCP (optional — needed only for interactive Blender work via Claude)

This project uses the **blender.org-maintained Blender MCP** (not the
third-party `ahujasid/blender-mcp` package some guides reference — do not
install both; a mismatched addon/client pair will not connect).

The project's `.mcp.json` (committed) points at a local clone:

```json
{
  "mcpServers": {
    "blender": {
      "type": "stdio",
      "command": "uv",
      "args": ["--directory", "${HOME}/tools/blender_mcp/mcp", "run", "blender-mcp"]
    }
  }
}
```

To set this up on a new machine:

1. Install `uv`/`uvx` (https://docs.astral.sh/uv/getting-started/installation/).
2. Clone the server: `git clone <blender_mcp repo> ~/tools/blender_mcp`
   (matches the path baked into `.mcp.json` above — use a different path
   and update `.mcp.json` if you'd rather put it elsewhere).
3. Install the add-on from `~/tools/blender_mcp/addon/blender_mcp_addon/`
   into Blender (Blender 4.2+ extension format — install via Blender's
   extension/add-on manager, pointing at that directory).
4. Launch Blender, enable the add-on, and start its server from the add-on
   preferences panel (optionally set it to auto-start).
5. Start (or restart) a Claude Code session from the repo root and run
   `/mcp` — confirm `blender` shows as connected.

**Caution:** this MCP executes AI-generated Python inside your running
Blender session without strong isolation. Commit your work before asset
operations you'd mind losing, and keep any hand-authored `.blend` sources
under version control separately from the generated `.glb` exports (see
`CLAUDE.md` → asset workflow).

## 4. Verify everything

```bash
tools/doctor.sh
tools/verify.sh
```

`doctor.sh` checks binaries/versions exist; `verify.sh` runs the actual
test suites. Both should pass clean on a correctly set-up machine.
